
# Історія української розвідки в інтерактиві

1. Розвідка у давні часи — Причини та передумови створення спеціальних розвідувальних служб, перші форми організованої розвідувальної діяльності на українських землях.

2. Розвідувальна діяльність середньовіччя — Методи розвідки у Київській Русі, козацька розвідувальна система та її вплив на історію України.

3. Сучасні органи розвідки України — Структура та функції сучасних розвідувальних служб:
    - Служба зовнішної розвідки України (СЗРУ)
    - Головне управління розвідки МО України (ГУР МО)
    - Служба безпеки України (СБУ)
